# Focus: Transcriber

**Goal:** A simple web page where I upload an audio file and get back a text transcript I can read and download.
**Done when:** I upload a 2-minute voice memo and get a readable transcript and a `.txt` download in under a minute, by 2026-11-19.
**Why now:** To learn the AI-native build method end to end (goal, interview, tickets, test-first build, review) on a small, real project.

## Vital few
1. Audio in, text out (the transcription call) : this is the product; nothing else matters if it fails.
2. Upload page that shows the transcript : how it is used, and the "readable transcript" part of done.
3. `.txt` download : written into "done when"; tiny, but the goal is not met without it.
4. Clear errors for wrong or too-big files : makes the 2-minute test reliable, not lucky.

## Not now

- Design polish, logo, dark mode
- Recording from the microphone
- Speaker labels, summaries, editing the transcript
- Accounts and saved history
